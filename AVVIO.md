# Avvio in 3 passi (tutto gratuito, nessuna registrazione)

1. Estrai lo zip e fai doppio clic su `setup_windows.bat` (Mac: `./setup_mac.sh`). Serve solo Python 3.11+.
2. Nella cartella apri Claude Code (`claude`).
3. Scrivi `/lab --fast`, poi `/fase 1` per ogni passo successivo.

Altri comandi: `/test`, `/titolo RACE.MI`. La app: `python app.py` → http://localhost:8000.
Risparmio token: `/model sonnet`, `/clear` tra un compito e l'altro.
